# La serie Samsung Galaxy S25 llega a todo el mundo
## Galaxy S25 simplifica y mejora la vida cotidiana a través de experiencias móviles intuitivas y multimodales basadas en AI e impulsadas por avances optimizados de hardware y software

Samsung Electronics anunció la disponibilidad a nivel mundial de la nueva serie Galaxy S25. Con la llegada de **One UI 7**, Gemini está disponible oficialmente en 46 idiomas[1], lo que facilita más que nunca las interacciones fluidas entre las aplicaciones de Samsung y Google.

![alt text](https://img.global.news.samsung.com/ar/wp-content/uploads/2025/01/1.-device-image_250121-1024x512.jpg)

- Los agentes de IA con capacidades multimodales están integrados en la plataforma One UI 7[2] para realizar tareas complejas sin problemas

- Now Brief[3] ofrece sugerencias personalizadas para guiarte a lo largo del día 

- Now Bar[4] ofrece un nuevo centro de actividades continuas.
